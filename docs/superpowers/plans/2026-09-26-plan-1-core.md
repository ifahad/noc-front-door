## Global Constraints

**Accounts and deployment**
- Trial account: exactly **1 assistant** (`sanad-noc`, id `assistant-a2d301b3-f112-48f6-84c8-9e4d052cf3b7`). Update it in place and never create a second one. There is no phone number, so testing uses web calls (Portal) and `/chat`.
- **KV namespace:** `noc-kv`, id `f08b8bc7-4208-4c63-9e8f-0f851d02cd0f`.
- **Edge secrets** (already set): `TELNYX_PUBLIC_KEY` (base64 raw 32-byte Ed25519), `MCP_TOKEN`, `OPS_TOKEN`, `PIN_PEPPER`. New in this plan: `ONCALL_NUMBER` (👤 Fahad's verified number, set via CLI) and `SEED_LOCAL` (JSON, see T3).
- **Actor-owner rule:** `noc-actors` declares only `[[actors]]`, with no KV, secrets or `[telnyx]` bindings. Actor modules import only `@telnyx/edge-runtime` and pure modules from `edge/shared`, with no top-level side effects (no `console` at module scope, no timers). Actor methods do **no** network I/O (C6).
- **Ship order:** `noc-actors` first, then `noc-edge`. A ship takes 15-35 min. A revision is live when `telnyx-edge deployments <fn>` shows it `ACTIVE (*)`, regardless of the CLI exit code. **Only the architect ships.** Batch changes to minimise ships.
- **Platform facts:** `/health/*` is intercepted by the platform, so our checks live under `/ops/*`. MCP is visible in **every** workflow node (`replace` does not hide it). LLM edge conditions must describe the **caller's latest utterance**. Prompt instructions are single-purpose.

**Data and logging**
- All dynamic-variable and webhook values are **strings**. Sentinels are `"none"` / `"unknown"` / `"false"`, never `""`.
- **Log format:** one JSON line per event, schema in spec §11.1.
- **Never log** PINs, PIN fingerprints, tokens, the API key, signature values or unmasked phone numbers. Masking rule: `+NNNN****NNN`.
- **KV keys:** one writer per key (spec §6.3). Keys match `^[-/_=.a-zA-Z0-9]+$`.
- **Promises:** no floating promises. Use `deadline()` from `edge/shared`.

**Tooling**
- **Pins:** exact versions, `npm i -E`, lockfiles committed.
- **Tests:** vitest in each edge package, and `node --test` for root scripts.
- **Commit trailer:** `Assisted-by: OpenCode (telnyx/<model>)`.
- **Default model:** `telnyx/zai-org/GLM-5.3-Flash --variant no-thinking`. Escalate to `zai-org/GLM-5.3`, then `moonshotai/Kimi-K3`, only after 3 failed fix rounds (SDD rule).

## Review Focus

Uncovered failure modes most likely to bite a caller or reviewer, with the test that pins each one:

1. **The web caller has no phone number.** `telnyx_end_user_target` is a SIP URI such as `xyz@sip.telnyx.eu`, so directory lookup must not crash or mis-parse. Expect `unverified`, unless the demo flag is set. → T7 test "sip uri caller".
2. **The DV webhook never arrives** (seen in 2 of 5 calls). Every tool must still work on defaults, with no ccid join from `/dv`. → T8 tests "no dv session" + P12/P21.
3. **Concurrent opens for one site** from different calls must produce 1 ticket. → T4 unit tests + T13 race test.
4. **Cross-tenant ids from the LLM** (a Rawda site from an Al-Waha session) must be refused by the MCP tools and the webhooks. → T8/T9 authz tests.
5. **Leftover fault flags** from a drill break the next demo run. → T10 reset test + `/ops/status` red flag.

### Task 2: Shared pure libraries (TDD)

**Files (🤖):** `edge/shared/src/{log,mask,ids,kvkeys,timing,ed25519}.ts` + tests. Port and generalise the tested probe modules (`edge/noc-probe/src/{log,util,ed25519}.ts`).

**Interfaces (produces):**
- `mask(s)`
- `logEvent(fields)`: one JSON line with the spec §11.1 schema; `svc` comes from the caller
- `sessionKey({call_control_id, call_key}): string|null`
  - It returns `sha256(call_control_id).slice(0,16)` when that is a non-empty string not containing `{{`.
  - Otherwise, when `call_key` is non-empty, not `"none"` and has no `{{`, it returns `sha256("key:"+call_key).slice(0,16)`.
  - Otherwise it returns `null`.
- `traceId(k)` → `"t-"+k`
- `mintTicketId(siteCode, seq)` → `NJD-${siteCode}${pad2(seq%100)}`
- `mintIncidentId(regionCode, seq)` → `INC-${regionCode}${pad3(seq%1000)}`
- `siteCodeOfTicket(id)` → the 2-digit code, or `null`
- `spellId(id)`: `"NJD-1407"` → `"N J D, 1 4 0 7"`
- `kvKey(...parts)`: joins with `/`, strips `+` and `:` (and any character outside the charset), and throws if the result is empty
- `deadline<T>(p, ms, label): Promise<{ok:true, value:T}|{ok:false, timeout:true}>`, which attaches `.catch` to `p` and logs late rejections
- `verifyTelnyxSignature(headers, raw, publicKeyB64)` → `valid|invalid|absent|error`, plus `isFresh(ts, nowSec, skewSec=300)`

| | a ccid of `""` with call_key `"v3:x"` | a key-derived key |
| | both `"none"`, or both containing `{{` | `null` |
| | two different call_keys | different keys |
| `mintTicketId` | code `"14"`, seq `7` | `"NJD-1407"` |
| `spellId` | `"INC-1002"` | `"I N C, 1 0 0 2"` |

| `deadline` | a promise that rejects after the timeout | no unhandledRejection, returns `timeout` |
