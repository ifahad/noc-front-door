# Probe results — Plan 0 evidence (2026-09-26)

## Method

A dedicated diagnostics function `noc-probe` and a probe assistant `sanad-noc` were deployed on the trial account. Evidence was gathered from 5 web calls and 1 chat turn against the assistant, direct HTTP probes of the function routes (`/dv`, `/tools/echo`, `/mcp`, `/health/*`, KV and actor routes), canary experiments on the same account (a stock CLI-scaffold `Counter` actor function), and balance reads. Every row below cites two independent witnesses; facts come only from `noc-probe` logs, Telnyx conversation transcripts, canary experiment results and recorded account state. Numbers that were not measured are not claimed.
