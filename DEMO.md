# DEMO.md — the interview demo (8–10 min, browser or phone)

The demo opens on the **site root** — **https://noc-edge-41d2a334-7.telnyxcompute.com/**, the production front page ("/demo" serves the same page). Every demo call can be a browser web call from the page, or — the account was verified on 2026-09-28 — a real call to the public line **+1 512 980 6105** (a US number; international from KSA). The **operator console is hidden**: press the backtick key or append `#console` to the URL (scenarios + the two demo PINs, detailed board, event feed, presenter controls). All commands read `.env` (`EDGE_URL`, `OPS_TOKEN`); `scripts/ops.mjs` never echoes the token. `$KV_ID` is the `noc-kv` namespace id (`telnyx-edge storage kv list` — get it once, runbook fault-drill preamble). The external prober must be running (runbook §6): it heals the KV projections (the sync check runs at most every 30 s) and claims/sends alarm pages every 30 s.

Pre-flight (run 5 minutes before, not during): start a screen recording of the dev box, keep `node scripts/prober.mjs` output, the invocation log (`telnyx-edge logs noc-edge --tail --type invocations`) and `/ops/status` open side by side.
